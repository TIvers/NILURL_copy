# NILURL_copy

Копия файлов структуры веб-приложения для сокращения ссылок и аналитики переходов с вырезанными ключевыми данными.

## Структура проекта

- **API FULL** — серверные PHP-скрипты для работы с API и проксированием. Разделены по категориям.
- **public/** — статические файлы, доступные напрямую (например, favicon, robots.txt, sitemap.xml).
- **src/** — исходный код фронтенда (React-компоненты, стили, утилиты).
- **updater/** — скрипты для обновления данных в базе.
- **vendor/** — сторонние библиотеки PHP, устанавливаемые через Composer.
- **node_modules/** — зависимости Node.js, устанавливаемые через npm.
- **build/** — собранная версия фронтенда для деплоя.
- **db.php** — настройки подключения к базе данных.
- **config-overrides.js** — кастомизация конфигурации сборки React.
- **generate-sitemap.js** — генерация sitemap для поисковых систем.
- **change-title.js** — автоматическая правка мета-тегов в index.html после сборки.
- **package.json, package-lock.json** — зависимости и скрипты Node.js.
- **tsconfig.json** — конфигурация TypeScript.
- **tailwind.config.js** — конфигурация Tailwind CSS.
